# Meu Site Pessoal — Praticando HTML Semântico

Este projeto foi desenvolvido como parte das atividades práticas da disciplina de **Desenvolvimento Web 1 (DWE1)** do curso de **Bacharelado em Sistemas de Informação** no **Instituto Federal de São Paulo (IFSP) — Campus Votuporanga**[cite: 1].

---

## 🎯 Objetivo do Projeto

O objetivo principal desta atividade é consolidar, na prática, os conceitos fundamentais da linguagem **HTML5**, com foco em:
- **HTML Semântico:** estruturação consciente de páginas utilizando tags com significado contextual (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<footer>`, etc.)[cite: 1].
- **Formatação de Texto Semântica:** aplicação prática e contextualizada de tags como `<strong>`, `<em>`, `<mark>`, `<abbr>`, `<blockquote>`, `<cite>`, `<sup>`/`<sub>`[cite: 1].
- **Navegação e Links:** construção de links internos, âncoras locais (`href="#id"`), links externos e botões de retorno ao topo[cite: 1].
- **Mídia e Incorporação:** uso adequado de imagens com textos alternativos descritivos (`alt`), galerias e incorporação de `<iframe>` (Google Maps e YouTube)[cite: 1].
- **HTML Puro:** foco exclusivo na hierarquia, acessibilidade e semântica do documento, sem a utilização de estilização CSS ou scripts JavaScript nesta etapa[cite: 1].

## 📁 Estrutura das Páginas

O site é composto por 5 páginas interligadas por um menu de navegação (`<nav>`) presente em todas elas[cite: 1]:

1. **`index.html` (Sobre Mim):**
   - Página inicial/hub com apresentação pessoal, foto de perfil, lista de interesses e links para contato e redes sociais[cite: 1, 3].
2. **`cidade.html` (Minha Cidade):**
   - Página com a história de Votuporanga-SP, significado do nome, primeiros moradores, principais pontos turísticos com imagens descritivas, link para a Wikipédia e mapa interativo incorporado via Google Maps[cite: 1, 2].
3. **`sonho.html` (Um Sonho):**
   - Narrativa pessoal sobre objetivos de vida, independência e carreira, acompanhada de uma galeria ilustrativa com imagens representativas[cite: 1, 5].
4. **`inspiracao.html` (Alguém que me Inspira):**
   - Biografia e reflexão sobre a pintora Frida Kahlo, contendo citações reais formatadas com `<blockquote>` e `<cite>`, além de link externo para o museu oficial[cite: 1, 4].
5. **`tematica.html` (Página Temática — Minhas Músicas Preferidas):**
   - Lista temática com músicas favoritas estruturada em blocos navegáveis por links âncora internos, com links de "Voltar ao topo" e players incorporados do YouTube[cite: 1, 6].
